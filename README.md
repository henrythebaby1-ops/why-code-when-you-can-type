# Why Code When You Can Type?

Little browser games for people who'd rather type than code.

- **Word Chain**: say a word, and the next word has to start with your last letter. Play against Pip the bot or a friend.
- **Hear It, Spell It**: listen to a word and type how it's spelled.
- **Unscramble Rush**: unscramble as many words as you can in 60 seconds.
- **The So Crazy Elevator**: an online multiplayer arcade survival game where every floor brings a new disaster. It uses peer-to-peer WebRTC through PeerJS, and the first player in a room hosts it.

Plain HTML, CSS and JS with no build step. Hosted on GitHub Pages.
